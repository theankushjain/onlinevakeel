All eight steps run in a fixed order inside a single request. Six of them are ordinary Python rules; only two call a language model, and both have a written-out fallback.

How to read these diagrams. Green blocks are rule-based and always run. Amber blocks call a language model when a key is configured, and use built-in legal templates when one is not. Red blocks sit outside the system and are all optional.
